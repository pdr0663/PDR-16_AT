### Why this matters

This backplane is the physical ISA expansion substrate for the machine, so its slot arrangement, bus routing, and power distribution will affect:

- card compatibility assumptions
- signal-loading expectations
- mechanical layout
- daughterboard attachment planning
- grounding and decoupling strategy

- Any silk-screened bus labels
- Power connector type

- Any documentation, jumper blocks, or option headers
